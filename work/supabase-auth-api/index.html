Case 05 / Express · TypeScript · Supabase Auth · OpenAPI

Supabase Auth API

Protected routes with server-side verification. An Express and TypeScript API that delegates identity to Supabase, verifies tokens server-side, and documents the flow in Swagger UI.

Open source folder ↗

Stack

  • Express
  • TypeScript
  • Supabase Auth
  • OpenAPI

Challenge

What needed to change

Add signup, login, logout, and protected routes without storing passwords or trusting a locally decoded JWT.

Approach

How I built it

  1. Forwarded credentials to Supabase Auth and used only its public anon key.
  2. Built middleware that extracts and verifies Bearer tokens with supabase.auth.getUser.
  3. Added OpenAPI docs and compared the implementation with an AI-generated rematch.

Result

What landed

Thirteen manual scenarios passed, including tampered-token rejection and post-logout revocation.

Honest limitation

What is not finished

There is no automated test suite or verified public API deployment yet.
