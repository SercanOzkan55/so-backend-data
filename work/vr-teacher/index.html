Case 03 / Unity · C# · FastAPI · ChromaDB · OpenAI

VR Teacher

An AI-supported electronics teacher inside a virtual classroom. A Unity VR learning environment that explains experiment PDFs, answers grounded voice questions, and guides interactive breadboard work.

Private repository

Stack

  • Unity
  • C#
  • FastAPI
  • ChromaDB
  • OpenAI

Challenge

What needed to change

Join immersive interaction, grounded teaching content, voice input, and circuit simulation without letting the AI drift away from the selected experiment sheet.

Approach

How I built it

  1. Built the classroom and electronics-lab client with Unity and XR Interaction Toolkit.
  2. Used a FastAPI backend for experiment-sheet management plus speech-to-text and text-to-speech bridges.
  3. Grounded answers in indexed PDF material and added circuit rules for shorts, LED current, capacitors, logic gates, and multimeter probes.

Result

What landed

The prototype connects a VR classroom, experiment phone UI, voice questions, RAG answers, and interactive electronics practice in one learning flow.

Honest limitation

What is not finished

It remains a private prototype; headset usability, learning outcomes, and production deployment still need measured validation.
