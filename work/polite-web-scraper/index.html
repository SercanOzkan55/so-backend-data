Case 04 / Node.js · Cheerio · JSONL · robots.txt

Polite Web Scraper

Structured data, collected with restraint. A modular scraper that checks robots.txt, rate-limits requests, cleans page values, and writes 1,000 book records as JSONL.

Open source folder ↗

Stack

  • Node.js
  • Cheerio
  • JSONL
  • robots.txt

Challenge

What needed to change

Turn catalogue pages into structured records while keeping crawl behavior respectful and reproducible.

Approach

How I built it

  1. Separated fetching, robots rules, parsing, cleaning, configuration, and orchestration.
  2. Sent an identifying User-Agent and delayed every request by 300ms.
  3. Converted price, stock, rating, category, and description into typed fields.

Result

What landed

A complete run walks 50 listing pages and produces roughly 1,000 clean records.

Honest limitation

What is not finished

Production use would need retries, observability, and selector-change monitoring.
