Case 02 / TypeScript · React · PixiJS · Web Worker · Vitest

Siliqon

An electronics laboratory that runs entirely in the browser. A visual breadboard simulator with real-time analog solving, measurement tools, deterministic safety warnings, and Arduino-style programming.

Private repository

Stack

  • TypeScript
  • React
  • PixiJS
  • Web Worker
  • Vitest

Challenge

What needed to change

Make circuit building feel visual and immediate while keeping electrical connectivity and simulation behavior technically consistent.

Approach

How I built it

  1. Separated the PixiJS laboratory scene from React panels and from the electrical netlist model.
  2. Reduced breadboard connections to active nodes, then solved analog behavior with modified nodal analysis and time-stepped simulation.
  3. Added a C-like microcontroller interpreter, oscilloscope, multimeter, deterministic fault rules, and portable project files.

Result

What landed

The current build supports prepared experiments, multiple development boards, transient RC and PWM behavior, and an 80-test simulation and interpreter suite.

Honest limitation

What is not finished

The education layer, AI assistant, advanced components, and public deployment are still roadmap work; the repository remains private.
