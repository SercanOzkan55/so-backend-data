Case 03 / Node.js · Express · SQLite · SQL

SQLite CRUD API

A familiar API backed by a real file. A task-management REST API using SQLite for zero-configuration relational persistence, filtering, sorting, statistics, and CRUD.

Open source folder ↗

Stack

  • Node.js
  • Express
  • SQLite
  • SQL

Challenge

What needed to change

Move a task API from memory into persistent SQL storage without changing the client interface.

Approach

How I built it

  1. Created a tasks table with timestamps and an auto-incrementing key.
  2. Mapped SQLite integer values to JSON booleans at the API boundary.
  3. Added search, state filtering, sorting, statistics, and SQL verification queries.

Result

What landed

A documented CRUD surface backed by a single-file database that standard SQLite tools can inspect.

Honest limitation

What is not finished
