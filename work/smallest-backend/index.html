Case 01 / Node.js · HTTP · JSON

Smallest Possible Backend

Two endpoints. One useful first step. A deliberately tiny Node.js server that makes the request-response cycle visible before frameworks or databases are added.

Open source folder ↗

Stack

  • Node.js
  • HTTP
  • JSON

Challenge

What needed to change

Build the smallest complete backend: listen for a request, choose a route, and return structured data.

Approach

How I built it

  1. Used Node's built-in HTTP server so the fundamentals stayed visible.
  2. Added GET / for a hello response and GET /time for live server time.
  3. Kept the run path to one command so the project is easy to inspect.

Result

What landed

A compact baseline for routing, status codes, headers, and JSON responses.

Honest limitation

What is not finished

The source pack has no recorded test run, automated tests, persistence, or deployment.
