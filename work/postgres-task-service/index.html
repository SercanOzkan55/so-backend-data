Case 02 / Express · TypeScript · PostgreSQL · Docker

PostgreSQL Task Service

Persistence without rewriting the service. An Express and TypeScript task API that switches between memory and PostgreSQL without changing routes or business logic.

Open source folder ↗

Stack

  • Express
  • TypeScript
  • PostgreSQL
  • Docker

Challenge

What needed to change

Replace temporary memory storage with a real database while preserving the API contract.

Approach

How I built it

  1. Defined a TaskRepository interface and made the service depend on the contract.
  2. Added a PostgreSQL implementation, pool, schema, and Docker Compose stack.
  3. Selected the repository from DATABASE_URL without changing routes or the service.

Result

What landed

Tasks survived full container removal and recreation because the data lived in a named volume.

Honest limitation

What is not finished

Redis and the index / EXPLAIN ANALYZE stretch goals remain undone.
