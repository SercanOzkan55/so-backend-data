Case 01 / Python · FastAPI · React · PostgreSQL · Celery

CV Analyzer

Deterministic where it can be, AI where it must be. A hybrid resume-intelligence platform for ATS analysis, recruiter workflows, CV building, and privacy-first local processing.

Open public repository ↗

Stack

  • Python
  • FastAPI
  • React
  • PostgreSQL
  • Celery

Challenge

What needed to change

Analyze varied resume formats, produce explainable ATS feedback, and support recruiter-scale workflows without sending every document to an LLM.

Approach

How I built it

  1. Built a deterministic extraction and normalization pipeline with a quality gate that invokes an LLM only for weak parses.
  2. Separated cloud accounts and collaboration from a local desktop worker for privacy-sensitive batch processing.
  3. Combined FastAPI services, PostgreSQL, Redis, Celery, S3-compatible storage, React, and automated security checks.

Result

What landed

The documented system spans four runtimes, 185 endpoints across 14 routers, recruiter and candidate workflows, multiple renderers, 800+ backend tests, 100 frontend tests, and 12 CI checks gating every pull request.

Honest limitation

What is not finished

The project is source-available for portfolio review rather than open source, and its production architecture requires several managed services.
